# eBookShop

A university web development project demonstrating a responsive e-commerce site for purchasing eBooks. 
Built as part of a Web Development unit, this project showcases HTML, CSS, JavaScript, and client-side validation skills.

---

## Features
- **Homepage**: Navigation bar, list of books with images, descriptions, and 'Pay' buttons. Responsive layout (desktop/tablet/mobile).  
- **Payment Page**: Accepts credit card details, validates input with JavaScript and Regular Expressions, sends JSON POST requests to a mock server, handles errors, and shows success messages.  
- **Success Page**: Displays confirmation and last four digits of the card.  

---

For educational purposes only. Demonstrates web development fundamentals, responsive design, and client-side validation suitable for a portfolio project.
